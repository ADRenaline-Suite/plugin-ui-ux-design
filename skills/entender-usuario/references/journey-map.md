# Journey map

Fuente: Nielsen Norman Group, Journey Mapping 101.

## Qué fija

La persona que aportó el usuario, el escenario, y las fases con acciones, pensamientos, emociones y oportunidades.

## Qué deja abierto

La solución de interfaz. Una oportunidad no es una pantalla.

## Cómo hacerlo

1. Copia la persona como la dio el usuario: nombre o rol, y lo que ya se sabe de ella. Si no hay persona, pídela y no escribas el mapa.
2. El escenario es la situación concreta en la que ocurre el objetivo (dónde, con qué prisa, con qué información). Si el usuario no lo dio, pídelo.
3. Las fases siguen el orden de las tareas, si ya existen. Si no existen, saca las fases del relato del usuario y no inventes tramos.
4. En cada fase escribe acción, pensamiento, emoción y oportunidad. Pensamiento y emoción salen de lo que el usuario contó (una cita, una queja, una observación). Si no hay evidencia, deja el campo en «sin evidencia» y pregunta. No rellenes una curva emocional.
5. La oportunidad dice qué habría que cambiar para esa fase. No dibujes la pantalla.

## Plantilla

```markdown
# Journey map — <tema>

- Persona: <como la dio el usuario>
- Escenario:
- Objetivo:
- Fuente: Nielsen Norman Group, Journey Mapping 101.

## Fases

### <fase>
- Acción:
- Pensamiento:
- Emoción:
- Oportunidad:
```

## Ejemplo

Persona (del usuario): «Ana, paga el pedido de la tienda una vez por semana desde el teléfono, en el traslado al trabajo.»

Fase «Confirmar el pago». Acción: acepta el cargo. Pensamiento: «sin evidencia». Emoción: «sin evidencia». Oportunidad: saber de inmediato si el cargo quedó hecho. Esa oportunidad se anota; la pantalla se pide a `concretar-pantalla`.
