Write the handoff of the screen.

1. Follow the skill `specify-screen` in this plugin.
2. This command fixes the piece. In that skill, read `references/handoff.md`. Do not ask again which piece it is.
3. Prerequisites: an `accepted` mock, a UI kit, copy, accessibility notes. If the mock or the kit is missing, write them in this turn with the templates in `references/handoff.md` (`single-task`, `linear-three`, preset `plain`) and record them under Assumed. Missing copy or notes leave the delivery `proposed`. Ask `plugin-ux-writing` for the copy and `plugin-accessibility` for the notes.

Before you close, evaluate `## Done` in that skill and in the reference this command names. Every item is true, or fix the delivery in this turn. Do not leave a file that fails an item. Do not mark it `accepted` while an item fails.
