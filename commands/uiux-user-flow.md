Dibuja el user flow de la tarea.

1. Sigue el skill `ordenar-pantallas` de este plugin.
2. Este command fija la pieza. En ese skill, lee `references/user-flow.md`. No vuelvas a preguntar qué pieza es.
3. El texto del usuario es la tarea y las pantallas. Si faltan, pídelas.
