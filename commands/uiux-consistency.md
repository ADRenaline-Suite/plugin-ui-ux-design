Check consistency with the UI kit.

1. Follow the skill `evaluate-ui` in this plugin.
2. This command fixes the piece. In that skill, read `references/consistency.md`. Do not ask again which piece it is.
3. Prerequisites: UI kit, screen. If either is missing, follow "When a prerequisite is missing" in that skill and the prompts in `references/consistency.md`. If this turn brings the tokens and there is no `accepted` kit, write the kit with `define-appearance` before comparing.
