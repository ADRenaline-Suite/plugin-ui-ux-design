Review the built screen against the handoff.

1. Follow the skill `evaluate-ui` in this plugin.
2. This command fixes the piece. In that skill, read `references/implementation-review.md`. Do not ask again which piece it is.
3. Prerequisites: screenshot or URL, handoff. The screenshot or the URL stops the delivery. Without an `accepted` handoff the delivery stays `proposed`. Follow "When a prerequisite is missing" in that skill and the prompts in `references/implementation-review.md`.
